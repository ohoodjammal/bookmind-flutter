# BookMind

BookMind is a Flutter book discovery application that allows users to search, explore, and save books using data fetched from a REST API.

## Features

- Browse recently added books
- Search for books
- Smart search suggestions
- View detailed book information
- Add and remove favorite books
- Share book links
- Category filtering
- Dark mode
- Loading and error states
- Retry failed API requests
- Animated splash screen

## Technologies

- Flutter
- Dart
- REST API
- HTTP
- JSON
- SharedPreferences
- share_plus
- url_launcher

## API

Book data is provided by the dBooks API.
